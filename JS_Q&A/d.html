JavaScript Interview Questions

1. What is JavaScript?
JavaScript is a programming language used to make web pages interactive and dynamic.
2. What are closures in JavaScript?
A closure is a function that remembers its outer variables even after the outer function has finished executing.
3. Difference between var, let, and const?
var is function-scoped, let and const are block-scoped. const values cannot be reassigned.
4. What is the DOM?
DOM (Document Object Model) is a programming interface that represents the structure of a web page as a tree of objects.
5. What is the difference between == and === in JavaScript?
== checks only value with type coercion, while === checks both value and type strictly.
6. What are arrow functions in JavaScript?
Arrow functions provide a shorter syntax for writing functions and do not have their own 'this' binding.
7. What is event bubbling in JavaScript?
Event bubbling is a type of event propagation where the event starts from the target element and bubbles up to its ancestors.
8. What are promises in JavaScript?
Promises represent the eventual completion (or failure) of an asynchronous operation and its resulting value.
9. What is async/await in JavaScript?
async/await is syntactic sugar built on top of promises to handle asynchronous code in a cleaner way.
10. What is hoisting in JavaScript?
Hoisting is JavaScript's behavior of moving variable and function declarations to the top of their scope before execution.
11. What is the difference between null and undefined?
undefined means a variable has been declared but not assigned a value, while null is an assigned value representing "no value".
12. What is NaN in JavaScript?
NaN stands for "Not-a-Number". It is a special value returned when a mathematical operation fails (e.g., 0/0).
